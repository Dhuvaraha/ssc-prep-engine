# Deployment

The app is prepared for a free-first split deployment.

## Frontend — Vercel

Use `frontend` as the project root.

Environment variable:

```
VITE_API_BASE_URL=https://YOUR-BACKEND-HOST/api/v1
```

The included `frontend/vercel.json` keeps React Router paths working when a page is refreshed.

## Backend — Render

The root `render.yaml` describes the FastAPI service.

Required environment values:

```
DATABASE_URL=<PostgreSQL connection string>
CORS_ORIGINS=https://YOUR-FRONTEND-HOST
```

`JWT_SECRET` should remain secret and is generated by the Render blueprint when supported.

## Database

For deployment, use PostgreSQL rather than the default local SQLite database. A free Supabase PostgreSQL project is sufficient for personal use.

## Private question assets

Do not commit private PDF-derived question assets to this public repository. The local/private asset directory remains ignored by Git. For a hosted private setup, move private assets to a private object store or persistent private disk before relying on visual questions remotely.

## Local development

Backend:

```bash
cd backend
python -m venv .venv
# activate the environment
pip install -r requirements.txt
python -m app.scripts.bootstrap_dev
uvicorn app.main:app --reload
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

The local frontend defaults to `http://localhost:8000/api/v1`.
