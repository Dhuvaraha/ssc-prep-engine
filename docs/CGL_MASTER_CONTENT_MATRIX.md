# SSC CGL Master Content Matrix — v1

## Source basis
This matrix combines:
- current SSC CGL subject scope and exam notices,
- topic-weightage/trend references from major SSC preparation platforms,
- private PYQ compilations supplied by the user,
- original question-design requirements for a private adaptive practice engine.

Private publisher text is not copied into the public repository. PYQ files are used for pattern/archetype analysis and remain private.

## Bank policy
For each topic:
- Priority 5: 100+ original variants
- Priority 4: 60+ original variants
- Priority 3: 40+ original variants
- PYQs are stored separately with year/shift/source metadata
- Every question has difficulty 1/2/3, expected time, archetype, solution, shortcut, trap and QA status

## Lesson package standard
Every topic lesson must contain:
1. prerequisite
2. core concept
3. formula/rule
4. recognition cues
5. standard method
6. fastest safe shortcut
7. easy worked example
8. exam-level worked example
9. hard variation
10. common traps
11. three-question quick check
12. start-practice action

## Question QA standard
Every generated/original question must pass:
- exactly one correct option
- solution recomputes the answer
- shortcut is valid
- distractors map to plausible mistakes
- difficulty rule is satisfied
- expected time exists
- topic + archetype tags exist
- visual asset exists where needed
- source/visibility status is correct
- duplicate fingerprint check passes
